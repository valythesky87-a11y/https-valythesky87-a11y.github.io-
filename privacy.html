2. 구글 캘린더 권한의 사용 범위

업무캘린더는 구글 캘린더 권한 https://www.googleapis.com/auth/calendar.events(모든 캘린더의 일정 보기·수정)를 요청하며, 실제로는 기본 캘린더에서 다음 용도로만 사용합니다.

  • 일정 읽기: 달력 화면 표시
  • 일정 제목 수정: 이용자가 체크하거나 해제할 때 제목 앞의 [완료]를 넣거나 빼기
  • 일정 날짜·제목 수정: 매월 초 이용자 본인이 만든 미완료 일정을 새 달 1일로 옮기고 (이월) 붙이기
  • 일정 만들기: 이용자가 화면에서 할 일을 등록하면 기본 캘린더에 종일 일정 만들기
  • 일정 삭제: 이용자가 화면에서 삭제를 확인하면 해당 일정 지우기 (이용자 본인이 만들고 다른 참석자가 없는 일정만)

다른 사람이 참석하는 일정, 다른 사람이 만든 일정, 근무 위치·부재중 등 특수 일정은 수정하거나 지우지 않습니다.

업무캘린더가 구글 API로 받은 정보의 사용과 이전은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
